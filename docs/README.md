## 🛠️ Inicio Rápido de la Documentación (Docsify)

Si deseas servir esta documentación de forma local con **Docsify CLI**:

1.  Instala docsify de forma global (requiere Node.js):
    ```bash
    npm install -g docsify-cli
    ```
2.  Inicia el servidor local desde la carpeta del proyecto:
    ```bash
    docsify serve docs
    ```
3.  Abre tu navegador en:
    [http://localhost:3000](http://localhost:3000)
